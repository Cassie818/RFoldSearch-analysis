# Recurrent 3Dr word controls: shared-universe results

The analysis contains 2054 recurrent four-token words. All RMSD distributions use Rfam-labelled occurrences with unique full residue-key mapping and complete base-inclusive atoms.

## Structural conservation

- Five-anchor median RMSD: candidates 0.616 Å; frequency-matched controls 0.773 Å; length-matched random windows 2.314 Å; sequence-matched windows 2.200 Å.
- Base-inclusive median RMSD: candidates 0.873 Å; frequency-matched controls 1.095 Å; length-matched random windows 2.948 Å; sequence-matched windows 2.822 Å.
- Candidate versus frequency-matched permutation tests: five-anchor P = 1.00e-04; base-inclusive P = 1.00e-04 (10000 permutations).

## Pairing categories

Biotite annotations assigned all 2054 words to one of four modal categories: standard helical 986, fully paired non-standard 310, partially unpaired 716 and fully unpaired 42.

## BGSU overlap

Using the at-least-one-residue definition, the observed median per-word overlap was 85.7%, versus 66.7% under the occurrence-matched random-window null (one-sided empirical P = 0.001; 1000 replicates).
Standard-helical words: observed 50.0%, null 66.7%, P = 1.000. All other words: observed 100.0%, null 67.9%, P = 0.003.
